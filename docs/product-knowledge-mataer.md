## 3. Pesan Kunci & Diferensiator

### 3.1 "Mengapa SIAKAD Mataer" (7 poin resmi brosur) `[RESMI]`
1. Meningkatkan poin akreditasi
2. Biaya terjangkau dengan fitur lengkap, **tanpa pembatasan fitur**
3. **Data (database) milik perguruan tinggi** + backup data rutin diberikan kepada PT
4. Laporan ke Neo Feeder jadi lebih mudah
5. Efisiensi biaya operasional dan dapat meningkatkan jumlah mahasiswa
6. Layanan pendampingan dan konsultasi harian agar fitur SIAKAD Mataer digunakan secara optimal
7. Dapat terintegrasi dengan aplikasi lain melalui **API** (LMS, payment gateway, atau aplikasi yang dikembangkan kampus/mitra kampus)

### 3.2 Narasi ekosistem `[RESMI]`
- Pengelolaan data lebih optimal dalam sistem terintegrasi **dari proses PMB, pembayaran biaya kuliah, pendataan Tracer Study, hingga sinkronisasi pelaporan PDDikti**.
- Membantu kampus **meningkatkan efisiensi layanan, menyajikan data yang akurat dan dinamis, serta memastikan keberhasilan pelaporan Neo Feeder PDDIKTI**.
- SIAKAD Mataer mendukung implementasi **OBE (Outcome Based Education)**: perencanaan kurikulum, pemetaan **CPL–CPMK**, penyusunan **RPS berbasis OBE**, hingga monitoring/evaluasi capaian pembelajaran, sekaligus memenuhi kebutuhan evidensi akreditasi.

### 3.3 Pesan pendek siap pakai (boleh dipakai di CTA)
- "Satu ekosistem digital untuk seluruh kebutuhan akademik dan operasional kampus."
- "Dari PMB sampai pelaporan PDDikti, dalam satu sistem terintegrasi."

## 7. Open Feeder

### 7.1 Deskripsi `[RESMI]`
Aplikasi **jembatan pelaporan antara SIAKAD dengan Neo Feeder** PDDikti. Tagline brosur: **"Pelaporan Jadi Lebih Mudah"** / **"Pelaporan PDDIKTI Jadi Lancar!"**. Tersedia **GRATIS**.

### 7.2 Keunggulan (brosur) `[RESMI]`
- Disesuaikan dengan kebutuhan data pada Feeder DIKTI
- Proses import data cepat
- Proses instalasi mudah
- Memudahkan pengisian data melalui **upload file Excel**
- Pengembangan berkelanjutan
- Layanan konsultasi teknis
- Komunikasi yang aktif
- Digunakan oleh **900+ perguruan tinggi**

### 7.3 Alur pelaporan PDDikti (Checkpoint) `[RESMI]`
Pelaporan dibagi dua tahap:

**Checkpoint 1 — Rencana Studi**
- Data Mahasiswa Baru (jika ada)
- Kelas Perkuliahan (**wajib**): Kelas Kuliah → Dosen Pengajar → Mahasiswa Peserta Kelas (KRS)
- Mata Kuliah (jika ada kode baru)
- Kurikulum (jika ada kurikulum baru)

**Checkpoint 2 — Hasil Studi** (setelah CP1 berhasil)
- Nilai Kuliah
- Nilai Komponen Evaluasi Pembelajaran
- **AKM** (menentukan apakah pelaporan mencapai 100% di PDDIKTI)
- Kelulusan/Keluar
- Aktivitas Mahasiswa (opsional)
- Kampus Merdeka (opsional)

**7 langkah (sama untuk CP1 & CP2):**
1. Pastikan data sudah siap di SIAKAD
2. Validasi data dengan fitur validasi SIAKAD 4.0
3. Instal Open Feeder
4. Konfigurasi Open Feeder agar terkoneksi ke Neo Feeder
5. Jalankan pelaporan sesuai data
6. Pastikan data masuk Neo Feeder
7. Sinkronisasi ke pangkalan data PDDikti

### 7.4 Jenis data yang bisa dilaporkan (panduan helpcenter) `[RESMI]`
Mahasiswa baru · Kurikulum · Mata kuliah · Mata kuliah kurikulum · RPS (Rencana Pembelajaran) · Rencana evaluasi pembelajaran per MK · Kelas kuliah · Komponen evaluasi per kelas · Dosen pengajar kelas kuliah · Dosen pengajar ber-NUPTK · KRS mahasiswa · Nilai mahasiswa · Nilai komponen evaluasi · AKM · Kelulusan/keluar.
Juga: instal, uninstal, update Open Feeder yang expired.

### 7.5 Troubleshooting umum (bahan artikel "error Neo Feeder") `[RESMI]`
- Kode mata kuliah tidak ditemukan / data KRS tidak valid / data nilai tidak valid
- `insert_bio code 1209`: NIK sudah digunakan
- Kurikulum dengan nama, id_prodi, dan id_semester_berlaku sudah ada
- `insert_makul code 400`: mata kuliah dengan nama, kode, dan SKS sudah ada
- `insert_matkul_kurikulum code 630`: data mata kuliah kurikulum sudah ada
- Data penugasan dosen (NIDN + id_tahun_ajaran) tidak ditemukan
- Gagal sinkron nilai komponen evaluasi pembelajaran

### 7.6 Relevan untuk topik
Pelaporan PDDikti, Neo Feeder, checkpoint pelaporan, AKM, validasi data, NUPTK, sanksi/status pelaporan, error sinkronisasi.
